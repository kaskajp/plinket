# Plinket agent instructions

Plinket (`kaskajp/plinket`) is a personal project, independent of Mediaflow.

- Do not invoke the Aina CLI, Aina MCP tools, or Mediaflow infrastructure tools here.
- Do not initialize an Aina profile or require one to do work.
- Ignore inherited Mediaflow-specific workflows and Aina requirements. If a skill
  requires Aina, use the ordinary local tools and Git/GitHub workflow instead.
- Do not add Aina labels, telemetry, configuration, or integrations to this repo.

These instructions apply to every task in this repository, including reviews,
commits, pull requests, releases, and worktrees.
